What you are looking at

  • Real data, recorded. The bridge polled Rejseplanen's API with a free Labs key (about one call every 20 seconds, København H and Nørreport boards plus journey details) and saved its three feeds once a minute. This page replays those files; nothing here calls Rejseplanen.
  • Matched to Rejseplanen's own GTFS. Every trip in the feed carries the trip_id from Rejseplanen's static timetable, the same file Google already uses for Denmark. Train positions on the map are placed from the live stop times.
  • S-tog only, on purpose. A free key allows a few hundred calls an hour. The same software covers every train, metro, light rail and bus in Denmark with operator access; it has been tested on all 44,319 trips of a day.
  • Valid GTFS-Realtime. MobilityData's validator reports 0 errors on the bridge's feeds, in CI on every change and nightly on live S-tog data.
